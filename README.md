# 🚀 Portafolio de Desarrollo y Gestión de Datos

¡Bienvenido a mi repositorio! Aquí encontrarás una recopilación de proyectos prácticos enfocados en **Data Management**, diseño de bases de datos relacionales y NoSQL, y programación orientada en lenguajes como C++, Java y SQL.

---

## 📂 Estructura del Repositorio

* **`SQL/`** : Contiene el script DDL de creación de bases de datos relacionales (ej. modelo de censo poblacional con normalización de tablas, llaves primarias/foráneas y relaciones 1:N y N:M).
* **`C++/`** : Prácticas y códigos fuente orientados a la lógica de programación utilizando la extensión `.cpp`.
* **`Java/`** : Estructuras de desarrollo y fundamentos de programación orientada a objetos.

---

## 🛠️ Habilidades Técnicas Demostradas
* **Bases de Datos:** PostgreSQL, MySQL, SQLite.
* **Lenguajes:** Python, C++, Java, JavaScript, SQL.
* **Control de Versiones:** Git y GitHub (Flujo de trabajo colaborativo, ramas y pull requests).
